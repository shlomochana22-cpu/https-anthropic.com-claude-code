# עמודי דגם רכב — נישה רביעית (פיילוט)

מטרה: לכבוש שאילתות "מצבר ל[יצרן] [דגם]" (כוונת חיפוש גבוהה, תחרות נמוכה), שמשלימות את ערים×יצרנים×קיבולת. כל עמוד = התאמת מצבר לדגם ספציפי לפי דור/שנה, עם מחיר, CTA, ו-FAQ.

## החלטות לאישור בעלים (לפני רולאאוט מלא)
1. **מבנה כתובת:** עמוד וורדפרס תחת היצרן? למשל `/manufacturer/טויוטה-toyota/קורולה/` — או עמוד עצמאי `/מצבר-לטויוטה-קורולה/`? (ממליץ: עמוד עצמאי עם slug עברי נקי, כמו הבלוג.)
2. **מנגנון:** עמוד Elementor חדש (לא term), כדי שנוכל להזריק schema (Product/Vehicle/FAQ) דרך ווידג'ט HTML — בניגוד ל-term_content שמסרס scripts.
3. **היקף פיילוט:** דגם 1 (קורולה). אם עובד ומדורג — להרחיב ל-10-15 דגמים מובילים (יאריס, מאזדה 3, ספורטג', i35, טוסון, קיה פיקנטו, סיויק, אוקטביה, גולף, ניסאן קשקאי).

## ⚠️ נתונים — חובה לאמת מול המחשבון (api.php) לפני פרסום
הטבלאות בקבצים אלה מבוססות על ידע כללי + מבנה; **כרום חייב לאמת כל שורה (קיבולת/קוטב/סוג/שנים) מול מחשבון ההתאמה** לפני הטמעה, ולהחליף לפי הנתון האמיתי. אסור לפרסם מספרים לא מאומתים.
