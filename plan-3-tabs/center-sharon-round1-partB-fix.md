**ב3. שאלה אחת חדשה בכל 6 העמודים** (רק שאלת מספר הרכב; שאלת המחיר בוטלה):
- **ש:** אפשר לבדוק איזה מצבר מתאים לרכב לפי מספר רכב?
- **ת:** כן. במחשבון התאמת המצבר באתר מקלידים את מספר הרכב, והמחשבון ממלא לבד את היצרן, הדגם והשנה ומציג את המצבר המתאים והמחיר.

איפה: בשדה `qna` (פריט אחרון) **ובנוסף** ב-`mainEntity` של בלוק ה-JSON-LD מסוג FAQPage ב-post_content, באותו נוסח. **ברעננה:** רק ל-qna ול-JSON-LD, **לא** לרשימת השאלות שבתוך התוכן. אם קיימת כבר שאלה דומה על מספר רכב, לדלג.

**אימות לכל עמוד:** diff = התוספת + השאלה (qna + JSON-LD) בלבד; JSON-LD עובר JSON.parse; Title/H1/Meta ללא שינוי; דף חי 200, 0 `<br>` בתוספת, הקישורים 200, השאלה החדשה מוצגת. רעננה ראשונה, לדווח ולהמשיך.
