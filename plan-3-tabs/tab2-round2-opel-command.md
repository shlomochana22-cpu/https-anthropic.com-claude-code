2. **יצירת טיוטה דרך REST:** `POST /wp-json/wp/v2/pages` עם title, slug, status=draft. העתק את `_elementor_data` מעמוד הייחוס **ID 4639** (קונטיינר אחד + ווידג'ט HTML אחד) דרך `GET /wp-json/wp/v2/pages/4639?context=edit`, והחלף רק את שדה ה-`html` של ווידג'ט ה-HTML בתוכן העמוד החדש. ודא גם `_elementor_edit_mode=builder` ו-`_elementor_template_type=wp-page`.
3. **אימות hash:** SHA-256 של ה-HTML של הווידג'ט מיד אחרי יצירת הטיוטה, אחרי הפרסום ואחרי TSF. שלושת ה-hash חייבים להיות זהים. לדווח.
4. **פרסום:** דרך Elementor `document/save/publish` (ajax `elementor_ajax`), ואז `GET /wp-json/wp/v2/pages/{ID}` לאימות `status: publish`. כפתור "פרסם" בעורך לא אמין.
5. **TSF (The SEO Framework):** בטופס העריכה של העמוד, Title ו-Meta Description לפי הנתונים למטה (הקלדה אמיתית, לא הדבקה לשדה מוסתר), לסמן **"Remove the site title"** (ה-Title כבר כולל "| מצבר הדרך"), לשמור.
6. **אימות בדף החי (אנונימי, ?nocache=1):** 200, H1 נכון, Title ו-Meta מ-TSF, הטבלה מוצגת, JSON-LD נטען (FAQPage + Service), הקישורים לדף הבית / במרכז / בשרון / המחשבון / רכזת אופל = 200, וגם הקישור לפורד פוקוס (5092) = 200. אחרי 4 העמודים: הקישורים לאופל אסטרה מתוך 4 עמודי הפורד = 200.
7. **Breeze:** Purge All פעם אחת אחרי 4 העמודים.
