# פרומפט מוכן ל-Claude בכרום (Claude for Chrome / claude.ai)

מה זה: הקובץ הזה מכיל פרומפטים מוכנים להדבקה ל-Claude שרץ בדפדפן ויש לו גישה לאתר WordPress החי (matzberimil.co.il), לאחסון ולגוגל. כל מה שדורש גישה לאתר ולא ניתן לעשות מקובצים בלבד נמצא כאן.

חשוב: בצעו את הבלוקים לפי הסדר. אל תתחילו את בלוק ה-SEO (בלוק ב והלאה) לפני שבלוק האבטחה (בלוק א) הושלם ואומת כנקי.

## בלוק א, אבטחה (חובה, קודם כול)

```

קונטקסט הפריצה הידוע:
- שני תוספים זדוניים שכבר הוסרו: Plugin-9cd3c6af ו-Plugin-9e9cd7ee.
- קוד זדוני ב-WPCode בקטע Footer שהתחזה ל-__performance_optimizer_v6, ומשך קוד מהדומיינים ntdnewtds.shop ו-dnsnewtds.shop.
- סקריפטים זדוניים שמתחלפים בין עמודים: obseu.bmccfortress.com, obseu.kingofbzcc.com, obseu.siliconvalleybz.com (כולם מצביעים לקובץ ns/fd5ee4a5ad7af62d38c616a5d8a99850.html).
- חשבונות מנהל חשודים: seobackup (נוצר 24.5) ו-dev_ijeiawo7, ויתכן נוספים. בסך הכל היו 6 מנהלים.
- בסריקה אחרונה הקוד הזדוני עדיין הופיע בעמודי חולון, ראשון לציון ובת ים. תל אביב ודף הבית כבר נקיים.

משימות, לפי הסדר:
1. קודם כול, הנחה אותי לגבות את האתר (קבצים + DB) דרך UpdraftPlus או פאנל האחסון.
2. עבור ל-WPCode -> All Snippets. עבור על כל ה-Snippets, ובמיוחד Header & Footer בקטע Footer. אתר וסמן כל קוד שמתחזה ל-__performance_optimizer_v6 או שמושך מהדומיינים שצוינו. הראה לי לפני מחיקה.
3. ערוך את עמודי חולון, ראשון לציון ובת ים ב-Elementor. חפש HTML widgets או קוד מוטמע שמכיל את הדומיינים obseu.* או את שם הקובץ ns/fd5ee4a5. הראה לי כל ממצא לפני הסרה.
4. עבור ל-Users -> Administrators. הצג לי את כל חשבונות המנהל. מחק את seobackup ואת dev_ijeiawo7, וכל מנהל שלא אזהה. שאל אותי על כל אחד שאתה לא בטוח לגביו.
5. התקן את Wordfence Security (אם לא מותקן) והרץ Scan מלא, כולל השוואת קבצי ליבה. דווח לי על כל ממצא.
6. הנחה אותי להחליף את כל הסיסמאות (WordPress admin, אחסון/cPanel, DB, FTP) ולהחליף את ה-Salts ב-wp-config.php.
7. עדכן את כל התוספים והליבה לגרסה אחרונה.
8. הרץ את Wordfence שוב עד שהסריקה נקייה לחלוטין, ונקה את ה-cache של WP Rocket.

בסוף, תן לי סיכום של מה נמצא, מה הוסר, ומה נשאר לבדוק.
```
