# NEXUS — Israeli Nightlife Portal

פורטל חיי לילה (RTL, עברית) לרכישת כרטיסים לאירועים, עם צד מפיק (Pro) וצד אדמין.
עיצוב: ניאון ליים `#bff520` + ציאן, גופן Varela Round, glassmorphism כהה, Tailwind CSS.

## הרצה

זהו פרויקט סטטי. פתחו את `index.html` בדפדפן, או הריצו שרת מקומי:

```bash
python3 -m http.server 8000
# ואז גלשו ל- http://localhost:8000
```

`index.html` הוא **מרכז הניווט (Hub)** שמקשר לכל 33 המסכים בתיקיית `screens/`.

## מבנה

```
index.html          # Hub — גלריית מסכים מקושרת
screens/            # 33 מסכים עצמאיים
```

### צד משתמש (קונה)
דף בית · חיפוש וגילוי · גילוי לפי מיקום · מרקטפלייס · עמוד אירוע · Live Story ·
מפת אירוע · סיכום הזמנה · תשלום · אישור רכישה · הכרטיסים שלי · מועדפים ·
מכירה חוזרת · דירוג ומשוב · ארנק · התראות · מרכז עזרה · פרופיל

**משפך רכישה קליק מלא:** דף בית → גילוי → אירוע → סיכום → תשלום → אישור → כרטיס

### צד מפיק (Pro)
כניסת מפיק · דשבורד מפיק · דשבורד יחצן · יצירת אירוע (3 שלבים) ·
סטטיסטיקות (×2) · לידרבורד · סורק QR · רשימות מוזמנים · קופונים · קמפיינים · מאגר לקוחות

**מסע יצירת אירוע קליק:** login → פרטים → כרטיסים → מדיה ויח״צ → דשבורד

### אדמין
ניהול דאטא גלובלי

## הערות
- כל מסך הוא HTML עצמאי עם Tailmind config משלו (כפי שיוצא מ-Stitch/Figma).

- השלב הבא המתוכנן: המרה ל-Next.js עם קומפוננטות משותפות, ואז חיבור Supabase.
