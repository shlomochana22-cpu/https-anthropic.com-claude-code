# חיפוש מצבר לפי מספר רכב: מאיפה הנתונים ואיך בונים (1/11/2026)

## 1. מקור הנתונים: מאגר הרכב של משרד התחבורה (חינם, ציבורי)
משרד התחבורה מפרסם את מאגר כלי הרכב הרשומים בישראל בפורטל הנתונים הפתוחים של הממשלה, data.gov.il, ומאפשר שאילתה לפי מספר רישוי דרך API ציבורי (CKAN), **בלי מפתח ובלי תשלום**. זה המקור שכל אתרי "בדיקת רכב לפי מספר" משתמשים בו, כולל האתר שבצילום.

- מאגר: "כלי רכב פרטיים ומסחריים עד 3.5 טון" (כ-4 מיליון שורות).
- מזהה המשאב (לאימות לפני שימוש, מזהים משתנים לפעמים): `053cea08-09bc-40ec-8f7a-156f0677aff3`.
- שאילתה לפי מספר רכב:
  `https://data.gov.il/api/3/action/datastore_search?resource_id=053cea08-09bc-40ec-8f7a-156f0677aff3&filters={"mispar_rechev":"12345678"}`
- שדות שחוזרים (לפי תיעוד ושימוש מוכר, לאמת בבדיקה חיה): `mispar_rechev` (מספר רכב), `tozeret_nm` (יצרן, למשל "מאזדה יפן"), `kinuy_mishari` (כינוי מסחרי, למשל "CX-5"), `degem_nm` (קוד דגם), `shnat_yitzur` (שנת ייצור), `sug_delek_nm` (סוג דלק: בנזין/דיזל/היברידי/חשמלי), `degem_manoa`, `nefach_manoa`, `ramat_gimur`, `tzeva_rechev`, `mivchan_acharon_dt`, `tokef_dt`, `baalut` (סוג בעלות: פרטי/חברה/ליסינג, בלי פרטי בעלים), `misgeret` (שלדה).
- מאגרים נוספים באותו פורטל: אופנועים, רכב כבד מעל 3.5 טון, רכבים שהורדו מהכביש, ו"מאגר דגמים" (מפרט טכני לפי קוד דגם: נפח מנוע, הנעה, סטארט-סטופ בחלק מהדגמים).
- פרטיות: הנתונים ציבוריים ואינם כוללים שם בעלים או כתובת. מותר להציג "הרכב שלך: מאזדה CX-5 2020".
- מגבלות: אין SLA, יש הגבלת קצב לא מתועדת, ומזהי המשאב משתנים לעיתים. לכן **לא לקרוא ל-API ישירות מהדפדפן של הגולש** אלא דרך השרת שלנו עם קאש.

**חלופות:** ספקי API מסחריים (למשל שירותי "בדיקת רכב" ו-Actor ב-Apify) עוטפים את אותו מאגר ממשלתי בתשלום. אין בהם ערך מעבר לנוחות. לא מומלץ.

## 2. איך זה עובד באתר של המתחרה (מהצילום)
מספר רכב → שורה "מאזדה · CX-5 · 2020" + תמונת הרכב + "הרכב שלך צריך: 65Ah · EFB · קוטביות ימין · Start-Stop" → 3 מצברים במלאי עם מחיר וכפתורי חיוג/וואטסאפ. כלומר: מאגר הרכב נותן יצרן/דגם/שנה, ואז **המחשבון שלהם** (כמו שלנו) נותן את המפרט.

## 3. איך בונים אצלנו (למתכנת, אחרי הניקוי)
יש לנו כבר את החצי השני: `/dev/api.php` (מחשבון) יודע לתת קיבולת, סוג (יפני/אירופאי), קוטב וסטארט-סטופ לפי יצרן, דגם ושנה, ו-112 עמודי דגם + ווידג'ט הקישור. חסר רק השלב הראשון: מספר רכב → יצרן, דגם, שנה.

**שלב א, שרת (PHP, ליד api.php):** endpoint חדש `plate.php?n=<מספר>`: ולידציה (7 או 8 ספרות), קריאה ל-data.gov.il עם timeout קצר, קאש תוצאות (transient/קובץ, 30 יום לכל מספר; רכב לא משנה דגם), החזרת JSON: יצרן, כינוי מסחרי, שנה, דלק. בלי מפתח API. לרשום בלוג רק מספר + זמן (לא לשמור היסטוריית חיפושים עם פרטים מזהים).

**שלב ב, מיפוי (החלק שדורש עבודה):** שמות היצרנים והדגמים במאגר הממשלתי שונים מאלה שבמחשבון שלנו. דוגמאות: `tozeret_nm` = "מאזדה יפן" / "טויוטה יפן" / "יונדאי קוריאה" / "ב.מ.וו גרמניה"; `kinuy_mishari` = "CX-5" / "COROLLA" / "I20" / "YARIS CROSS". טבלת מיפוי: (א) יצרן: ניקוי המדינה ("מאזדה יפן" → "מאזדה") + טבלה ידנית ל-51 היצרנים שבמחשבון; (ב) דגם: נרמול (אותיות גדולות, הסרת מקפים ורווחים) + טבלת מיפוי ידנית לכ-712 הרכבים שבמחשבון (אפשר לבנות אותה חצי-אוטומטית מהמאגר: לכל יצרן, רשימת `kinuy_mishari` הנפוצים מול רשימת הדגמים שלנו). מה שלא ממופה: נופלים לבחירה ידנית במחשבון עם היצרן והשנה כבר ממולאים.

**שלב ג, ממשק (אלמנטור, ווידג'ט HTML חדש מעל המחשבון הקיים):** שדה "מספר רכב" + כפתור "בדוק". תוצאה: "הרכב שלך: מאזדה CX-5 2020" → קריאה אוטומטית למחשבון הקיים (אותו קוד, אותם שדות `#manufacturer/#model/#year`) → המפרט + הקישור לעמוד הדגם (הווידג'ט 5c0b4e23 כבר עושה את זה) + כפתורי חיוג ווואטסאפ עם הודעה מוכנה ("היי, צריך מצבר למאזדה CX-5 2020, מספר רכב ___"). לא נוגעים בקוד המחשבון הקיים, רק ממלאים את השדות שלו.

**שלב ד, מדידה ו-SEO:** אירוע GA4 `plate_lookup` (הצלחה/לא נמצא/לא ממופה). העמוד עצמו נשאר עמוד המחשבון (לא עמוד חדש). בטקסט העמוד להוסיף "בדיקת מצבר לפי מספר רכב" (יש ביקוש לשאילתה הזו).

**הערכת היקף:** שרת 2 עד 4 שעות; מיפוי יצרנים שעה; מיפוי דגמים 4 עד 8 שעות (הסוכן יכול להכין את טבלת המיפוי מהנתונים אם המפעיל יוריד דגימות מה-API); ממשק 3 עד 4 שעות. סך הכל יום עד יומיים עבודה של מתכנת + הכנת המיפוי אצלנו.

## 4. לפני שמתחילים: אימות חי (כרום, קריאה בלבד, 10 דקות)
1. לפתוח בדפדפן: `https://data.gov.il/api/3/action/datastore_search?resource_id=053cea08-09bc-40ec-8f7a-156f0677aff3&limit=1` ולדווח: `success: true`? רשימת השדות (fields) המדויקת.
2. אותו URL עם `&filters={"mispar_rechev":"<מספר הרכב של הבעלים>"}` (הבעלים נותן מספר אמיתי): האם חוזרת שורה, ומה הערכים ב-`tozeret_nm`, `kinuy_mishari`, `shnat_yitzur`, `sug_delek_nm`.
3. לבדוק 3 מספרים נוספים של רכבים מוכרים (למשל של הטכנאי) כדי לראות את מגוון הכתיב ב-`tozeret_nm` ו-`kinuy_mishari`.
4. לבדוק אם ה-API מחזיר כותרת `Access-Control-Allow-Origin` (אם כן, אפשר גם אב-טיפוס בצד הלקוח; בכל מקרה הייצור דרך השרת).
5. לחפש בפורטל את "מאגר דגמים" (מפרט טכני לפי קוד דגם) ולדווח את מזהה המשאב והשדות.
