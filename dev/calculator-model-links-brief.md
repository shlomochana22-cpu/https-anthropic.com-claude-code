## משימה 1: קישור מתוצאת מחשבון ההתאמה לעמוד הדגם

### מה רוצים
כשגולש בוחר במחשבון (https://matzberimil.co.il/battery-compatibility/) יצרן, דגם ושנה ומקבל תוצאה,
מתחת לתוצאה יופיע קישור לעמוד הדגם המתאים באתר, למשל:

> **מדריך מלא: מצבר לסובארו פורסטר - מחיר, סימנים והחלפה עד הבית**

יש באתר 112 עמודי דגם כאלה (רשימה מלאה בקובץ `dev/model-page-url-map.csv`).
לדגם שאין לו עמוד, הקישור מפנה לעמוד היצרן (`/manufacturer/<slug>/`).

### למה
המחשבון הוא העמוד החזק באתר. הקישור מעביר כוח SEO ל-112 עמודי הדגם ומעביר את הגולש מתוצאה יבשה לעמוד עם מחיר, סימנים וכפתור חיוג.

### מה כבר ידוע על המחשבון (נבדק 14/10/2026)
- הקוד של המחשבון הוא **inline בווידג'ט HTML של אלמנטור** בעמוד battery-compatibility, אלמנט `b2279cb` (`div.elementor-element-b2279cb.elementor-widget-html`). אין קובץ JS חיצוני. בקוד: `const server = "https://matzberimil.co.il/dev"`, jQuery + Select2, שדות `#manufacturer` / `#model` / `#year`, כפתור `#searchBtn`.
- התוצאה נבנית לתוך `div#result` (בתוך `div.battery-search`): `div.battery-card` > `div.battery-image` (img) + `div.battery-info` (`h3` "מצבר מתאים" + `table.battery-table`). כשאין התאמה: `<p>לא נמצא מצבר מתאים</p>`. **אין שום קישור בתוצאה כיום.**
- תשובת `api.php` עם יצרן+דגם+שנה: `status`, `count`, `data[]` ובכל רשומה `battery_id`, `battery_type`, `height`, `dimensions`, `pole`, `notes`, `engine_petrol/diesel/hybrid/electric`.
- **שמות היצרנים והדגמים ב-API שונים מה-slug של העמודים** (למשל "ניסן" / "מיציבושי" / "בי-ווי-די - BYD" / "אם ג׳י - MG" ביצרנים; "קרוסטר", "סאנדרו", "ראב 4 - RAV4", "SX4 קרוסובר", "ג׳אז" בדגמים). לכן אין לבנות כתובת מהשם. יש טבלת מיפוי מוכנה.

### המיפוי המוכן
קובץ **`dev/calculator-model-links.json`**:
```
{
  "models": { "<יצרן כפי שמוחזר מ-api.php>|<דגם כפי שמוחזר מ-api.php>": "<URL עמוד הדגם>", ... },   // 114 מפתחות → 112 עמודים
  "manufacturers": { "<יצרן כפי שמוחזר מ-api.php>": "<URL עמוד היצרן>", ... }                          // 18 יצרנים (fallback)
}
```
המפתחות הם **מחרוזת-למחרוזת** מול מה ש-`api.php` מחזיר, כולל סוג הגרש (ASCII `'` ברוב השמות; גרש עברי `׳` ב-"אם ג׳י - MG" וב-"ג׳אז"). שני דגמים ב-API ממופים לאותו עמוד בכוונה ("SX קרוסובר" + "SX4 קרוסובר"; "יאריס" + "יאריס קרוס"). כל 112 הכתובות אומתו 200 ב-14/10/2026.

### איך (הצעה, לא חובה)
1. **טבלת המיפוי** בצד השרת: לטעון את ה-JSON (או להמיר למערך PHP) בקובץ חדש ליד `api.php`.
2. **ב-API:** `api.php?manufacturer=X&model=Y&year=Z` יחזיר שני שדות נוספים ברמה העליונה: `model_page_url` (או `null`) ו-`manufacturer_page_url` (או `null`). החיפוש: קודם `models["X|Y"]`, ואם אין, `manufacturers["X"]`.
3. **בווידג'ט (inline JS ב-`b2279cb`):** אחרי בניית `div.battery-card`, להוסיף בתוך `div.battery-info` שורה אחת:
   ```html
   <p class="mb-model-link"><a href="<model_page_url>" data-mb="model-link">מדריך מלא: מצבר ל<יצרן> <דגם> - מחיר, סימנים והחלפה עד הבית</a></p>
   ```
   קישור פנימי רגיל (בלי `nofollow`, בלי `target="_blank"`). ה-`data-mb` משמש למדידה במשימה 2. שם היצרן והדגם בטקסט: להשתמש בשמות **הקצרים** מהעמוד (כותרת העמוד ב-`dev/model-page-url-map.csv`), לא בשמות הארוכים מה-API ("ראב 4 - RAV4"). אפשר פשוט להציג "מדריך מלא לדגם זה: מחיר, סימנים והחלפה עד הבית" בלי שמות, וזה גם בסדר.
4. **ברירת מחדל:** אם יש רק `manufacturer_page_url`, אותו עיצוב עם הטקסט "כל דגמי <יצרן>: מחירון והתאמה". אם אין אף אחד מהם, לא להציג שורה.
5. עריכת הווידג'ט: לערוך את ה-HTML של האלמנט `b2279cb` באלמנטור, או דרך REST (`_elementor_data`). לשמור עותק של הקוד הנוכחי לפני השינוי.

### מה לא לעשות
- לא להתקין תוספים חדשים (כלל קבוע באתר).
- לא לשנות את לוגיקת ההתאמה של המחשבון, רק להוסיף שדה ושורה.
- לא לשנות את ה-HTML של עמודי הדגם עצמם.
- לכתוב קוד חדש בקובץ נפרד, לא לערוך תוספים קיימים (בפרט לא את התוספים החשודים שמופיעים בדוח האבטחה).

### בדיקות קבלה
1. סובארו → פורסטר → 2018: מופיע קישור ל-`/מצבר-לסובארו-פורסטר/` והוא מחזיר 200.
2. סובארו → קרוסטר → 2024: מופיע קישור ל-`/מצבר-לסובארו-קרוסטרק/` (שם הדגם ב-API שונה משם העמוד, המיפוי מטפל בזה).
3. סובארו → BRZ → 2015 (אין עמוד): מופיע קישור לעמוד היצרן סובארו.
4. יצרן שאין לו עמודי דגם (למשל פורד): קישור לעמוד היצרן בלבד, בלי שגיאה.
5. המחשבון עובד בדיוק כמו קודם בכל שאר המובנים (זמן תגובה, תוצאות, מובייל).
6. בקוד המקור של דף המחשבון אין סקריפט חיצוני חדש.

### קבצים מצורפים
- `dev/calculator-model-links.json`: המיפוי המוכן (114 מפתחות + 18 יצרנים).
- `dev/model-page-url-map.csv`: אותן 112 כתובות עם כותרת העמוד ושם הדגם הקצר, לקריאה אנושית.
- כשמתווספים עמודי דגם חדשים נשלח JSON מעודכן. כדאי שהקובץ ייטען מהדיסק ולא יוטמע בקוד, כדי שעדכון יהיה החלפת קובץ בלבד.

## משימה 2: מדידת לחיצות טלפון ווואטסאפ (אחרי משימה 1)

### מה רוצים
לדעת מאיזה עמוד באתר מגיעות שיחות והודעות. כרגע אין מדידה של לחיצות על `tel:` ועל `wa.me`.

### איך
- אם יש כבר GA4 או Google Tag Manager באתר: להוסיף טריגר ל-`click` על קישורים שמתחילים ב-`tel:` ו-`https://wa.me/`, ואירועים `click_call` ו-`click_whatsapp` עם הפרמטרים `page_location` ו-`link_text`. ב-GA4 לסמן את שניהם כ-Key events (המרות).
- אם אין GA4: להוסיף gtag.js של GA4 ישירות בתבנית (לא דרך תוסף), ואז כנ"ל.
- בנוסף: אירוע `model_link_click` על `[data-mb="model-link"]` מהמחשבון (משימה 1), כדי למדוד כמה גולשים עוברים מהמחשבון לעמוד הדגם.

### בדיקות קבלה
1. לחיצה על "חייגו עכשיו" בעמוד דגם במובייל מופיעה ב-GA4 Realtime כ-`click_call` עם כתובת העמוד.
2. לחיצה על וואטסאפ מופיעה כ-`click_whatsapp`.
3. שני האירועים מסומנים כ-Key events.
4. אין האטה מורגשת בטעינת העמודים.
